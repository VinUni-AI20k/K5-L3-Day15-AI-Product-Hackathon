06 · Chi phí khi dùng thật

Mỗi dòng sản phẩm chỉ gọi model 1–2 lần

  • Code làm mọi bước kiểm → dòng lỗi không tốn token
  • Tối đa 2 lần gọi model / dòng (viết + viết lại)
  • Token lấy từ usage của API, không ước lượng
  • Mô phỏng ≥50 phiên theo persona: python run.py simulate --rate-from eval/run-2.csv
  • Chi phí / task thành công và 3 kịch bản: cost/cost-estimate.md
