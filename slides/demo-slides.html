2. Vì sao chọn bài này

  • 5/6 đang dùng ChatGPT thủ công · 5/6 lưu dữ liệu gốc ở Excel/CSV/Google Sheet → đầu vào sẵn có

3. Giải pháp: workflow cố định, AI chỉ viết câu chữ

  • Tải file sản phẩm → mỗi dòng: AI viết bài nháp hoặc đánh dấu dòng thiếu / mâu thuẫn, không bịa
  • Code kiểm trước AI: check_product (giá, size, giá sàn, chèn lệnh) · check_stock (chỉ màu/size còn tồn)
  • 1 lần gọi model mỗi dòng · code kiểm sau: verify_post (giá lệch ≤2%, cụm cấm, freeship chỉ khi file có) → sai thì viết lại 1 lần rồi đánh dấu
  • Người duyệt mọi bài · bài lên Facebook dạng hẹn giờ, huỷ được
